# Provider Icon Sources

This local icon pack supports the `modelProviders` field in `manual-card-facts.js`.

- Simple Icons assets: Anthropic, DeepSeek, Google, Qwen, Moonshot AI, ByteDance, Baidu, MiniMax, xAI, Mistral AI, and Meta. Simple Icons is CC0-1.0.
- Official public favicon or logo assets: OpenAI, NovelAI, Zhipu AI, Tencent Hunyuan, Cohere, Stability AI, iFlytek, Xiaomi, and SenseTime.

The package is intentionally limited to provider identifiers used by the directory or likely to be added to it. Do not use an icon to imply that a site supports that provider without a reviewed `modelProviders` entry.
